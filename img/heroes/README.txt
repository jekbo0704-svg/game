Талаптар:
- Портрет, бет анық көрінсін. Кемінде 600 пиксель ені.
- Тік (3:4) немесе шаршы фото жақсы.
- Таңдау экранында фото толық көрсетіледі, ойында беттің тұсы дөңгелекке қиылады.

Ойындағы дөңгелекке бет дұрыс түспесе, js/data.js файлында сол кейіпкердің
face жолын өзгертіңіз:
  face: { x: 0.5, y: 0.35, size: 0.6 }
  x    — беттің көлденең ортасы (0 = сол жақ шет, 1 = оң жақ шет)
  y    — беттің тік ортасы (0 = жоғарғы шет, 1 = төменгі шет)
  size — дөңгелек фотоның енінің қанша бөлігін алады (кішірек = үлкейтілген бет)

Басқа формат (.png, .webp) қолдансаңыз, data.js-тегі photo жолындағы
файл атын да өзгертіңіз. Фото жоқ болса, түсті дөңгелек пен инициал шығады.
